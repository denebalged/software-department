# Definition of Done — Checklist global

Un artefacto está "hecho" si cumple TODOS estos puntos.

## Universales
- [ ] ID único y estado (draft/review/approved/superseded)
- [ ] Fecha y autor
- [ ] Enlaces upstream y downstream
- [ ] Preguntas abiertas listadas
- [ ] Revisado contra los 8 principios del SKILL.md

## Código
- [ ] Tests unitarios y de integración
- [ ] Sin secretos en repo
- [ ] Lint y formato aplicados
- [ ] Auditoría registrada en mutaciones

## Documentación
- [ ] Documento correspondiente actualizado
- [ ] Glosario actualizado si aplica
- [ ] ADR creado si hubo decisión no obvia

## Seguridad
- [ ] Threat model si aplica
- [ ] Permisos revisados
- [ ] Datos clasificados

## Release
- [ ] Notas escritas
- [ ] Plan de rollback
- [ ] Monitoreo mínimo
