# Software Department

Skill reutilizable para diseñar y construir software con
prácticas auditables y ahorro de tokens.

## Uso en un proyecto
git submodule add <url-repo> .software-department

Luego copia `AGENTS.md`, `CLAUDE.md`, `.cursor/` y `.github/`
a la raíz del proyecto.

## Estructura
- SKILL.md — núcleo
- LOADING.md — reglas de carga y ahorro de tokens
- roles/ — 8 roles bajo demanda
- templates/ — 11 plantillas
- processes/ — 4 procesos
- snippets/ — bloques reutilizables

## Compatibilidad
VS Code, Antigravity, DeepSeek, Cursor, Claude Code, Copilot.

## Ahorro de tokens
Ver LOADING.md. Diseñado para cargar solo lo necesario.
