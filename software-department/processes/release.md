# Proceso: Release

## Cuándo
Al cerrar una versión.

## Pasos
1. Congelar features.
2. Ejecutar test plan.
3. Revisar Definition of Done.
4. Escribir release notes.
5. Definir plan de rollback.
6. Desplegar a staging → validar → producción.
7. Etiquetar versión en Git.
8. Actualizar roadmap.

## Criterio de salida
- Release notes publicadas
- Rollback probado
- Monitoreo activo
- CHANGELOG actualizado
