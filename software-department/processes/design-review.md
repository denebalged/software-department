# Proceso: Design Review

## Cuándo
Antes de codear algo no trivial.

## Checklist
- [ ] ¿Hay ADR si hubo decisión no obvia?
- [ ] ¿El modelo de datos está claro y auditado?
- [ ] ¿El contrato de API está definido?
- [ ] ¿Se consideraron los 4 estados UX?
- [ ] ¿Threat model si toca auth o datos?
- [ ] ¿Definition of Done clara?

## Salida
- Aprobado → empezar a codear
- Rechazado → volver al artefacto faltante
