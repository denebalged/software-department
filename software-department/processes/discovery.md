# Proceso: Discovery

## Cuándo
Al iniciar proyecto o feature grande.

## Pasos
1. Rellenar `docs/context.md` (PM).
2. Rellenar `docs/stakeholders.md` (PM).
3. Construir `docs/glossary.md` (PM + Arquitecto).
4. Definir `docs/roadmap.md` por fases (PM).
5. Listar requisitos REQ-XXX (PM).
6. Identificar decisiones técnicas tempranas → ADRs (Arquitecto).
7. Threat model inicial si hay datos sensibles (Security).

## Criterio de salida
- Contexto, stakeholders, glosario cerrados
- Roadmap con al menos una fase
- Al menos 3 REQ priorizados
- Decisiones críticas documentadas como ADR
